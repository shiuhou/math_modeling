# 本機資料

此目錄的資料預設不進 Git。多任務共用的大型原始資料可放到 `TEAM_DATA_DIR` 指定的位置，不需每個 worktree 複製一份。

資料來源與共用介面記在 [專案入口](../docs/brief.md)。目前資料檔案、授權、來源、版本與取得方式均待確認，沒有已核實的資料清單。只有實際取得且獲授權讀取後，才記錄真實檔名、雜湊、欄位、單位、時間範圍與限制。

依 [規範](../modeling.md) 第 3 章保持原始資料不變，由程式產生衍生資料。沒有公開授權不上傳原始或私有資料；ignore 不能移除已追蹤的敏感檔案，發現時應報告並等待處理授權。

工程檢查需要合成資料時，明確標為 fixture 並說明用途；其通過不代表真實資料驗證。正式實驗的資料版本與切分記在 [results 清單](../results/README.md)，大型資料使用已確認、穩定且具存取授權的保留位置。
