# 交接

讀取目前工作目錄、相關修改與任務筆記，更新 `notes/tasks/<任務>.md`。一小段能讓下一人直接開工的摘要就夠了：

- 目前完成到哪裡，以及重要檔案／結果位置。
- 下一個有價值的動作；有阻塞才寫阻塞。
- 必要的執行命令；已有 commit 才附 hash，未跑的部分照實標示。

不抄整段對話，不為交接重跑實驗，也不自行 commit 或替下一人重開 Codex。

隊員各自在不同電腦工作。交接提供已推送的任務分支／提交或 PR，並說明尚未提交或只在本機的資料與輸出。透過 GitHub Issue／PR 協調，發送留言仍依使用者授權；不要把本機 `team.py note` 當成能同步給隊友的訊息。
