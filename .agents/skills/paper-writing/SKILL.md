# 論文

以問題、模型選擇與主要發現串起論述，篇幅配置由內容價值決定，不把模板章節當作必填清單。

沿用團隊已採用的符號、假設與接口。需要改動核心定義時，先和相關任務對齊，避免在文章中悄悄換模型。

可先完成推導、方法與解釋框架。尚無實測結果的段落標註「待實驗填入」，不用虛構數字把文章補滿。

讓關鍵結論對應到實際結果、程式輸出或可查的引用；沒有必要為每句常識加引用，也不重述整份實驗日誌。

直接修改相關章節，保留對讀者有用的限制與洞見；不另外製作冗長的潤稿報告。
