# 資料與圖表

圍繞建模問題挑選有用的資料與呈現方式，不為完整性產出一整套無關 EDA。

先釐清來源、欄位、單位與會影響模型的缺漏；缺資料時說明可替代的來源或假設，不把合成資料冒充觀測資料。

保留原始資料，讓清理與轉換可由程式重做。共享資料可從 `TEAM_DATA_DIR` 讀取，各任務輸出放自己的 `outputs/`。

實驗／分析執行留給隊員時，準備可執行程式與短命令；已有實際輸出時再解讀。圖表優先呈現要支持的結論，補足座標、單位與必要圖說。

只保留會進入模型或論文的重點，以及其對應資料／程式位置。
