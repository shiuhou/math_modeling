# Q2 V2 K/timer ablation

Four SPT-FILL configurations, two ordinary SPT-HOL event modes, and one SPT-HEAD-TIME candidate were run at both the 65,536 A10 prefix and the full 111,284 A10 set. Each child used 900 s/4 GiB, FF-id, theta 604800 s, horizon 7776000 s, and was independently replayed. The compact comparison and manifest are committed; per-job files remain in reproducible ignored `outputs/q2-v2-*` directories.

`comparison.json` is generated by `problems/2026_gpu_scheduling/experiments/analyze_v2.py`.
