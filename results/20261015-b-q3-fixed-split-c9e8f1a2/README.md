# Q3 第一輪固定分流實測結果

研究主線為有限、整卡、啟動前 Cross-GPU Substitution。來源採納／修訂／排除、數學約束與凍結規則見 [模型](../../problems/2026_gpu_scheduling/docs/q3_model.md)，原始來源及 SHA256 見 [sources.json](sources.json)。配置為 60 台完整 A100、10% 全 trace 雜湊分流、假設 sigma=1。M1 與 M0 使用同一 224112 作業集合及同一原生政策；沒有新增物理容量。

本 trace 111284 個原生 A10 都符合空池形狀要求，選中 11209（10.0724%），占 A10 原 GPU-work 9.95068%。全部原生 A100 80877 個皆保留。60 台外來分區共有 480 GPU、7680 vCPU；其餘 372 台供原生 A100 使用。

## 原生接收池損失

兩政策的全部 80877 個原生 A100 作業，在 M0/M1 都是零等待；額外等待均值、P99、Max、正額外等待總量、原零等待新增延遲數皆為 0。其 JCT 不變：平均 27.248370h、P99 684.614511h、Max 4415.999722h；窗口完成 80101，完整排空完成 80877。逐 ID 配對證實，不是未計入 native donor cost。分區仍使它們少 60 台可用節點，這個 trace 尚未因此排隊；不能推廣為未來零損失保證。

## 下一輪 GO／NO-GO

**GO（模型與反事實驗證）**：可進少量預先指定的單因素情景；不是部署／實際效能批准。後續 routing 5%/20%、30/90 節點、sigma=2 各自與本情景比較，尚未執行。60 非已證最佳值。因沒有 benchmark，本次只主張 sigma=1 下結果；系統級 break-even threshold 尚未求得，需逐 sigma 重排並同時計入 native harm。動態借用、MIG、RL、拍賣、遷移、額外 scheduler 與 Initial Job Relocation 均不在本輪。

第一輪成功標準已達：固定分流物理合法且完整反事實可核對；停止於此，不自動啟動敏感度。
